# Starlight Swarm — visual contract

This file outranks every skill in the web-excellence pack.

## Direction (2026-08-28)

**Winner: Kernel Observatory.** Same brand tokens as the existing cockpit. New information architecture.

Compared and rejected:

1. **Light editorial manifesto** — fights the operator surface and the existing dark identity.
2. **Bloomberg-density terminal** — fails 375px, contrast, and keyboard use.

## Tokens of record

- Background: `hsl(240, 20%, 6%)` — never pure `#000`.
- Surface: translucent `hsla(240, 16%, 12%, 0.72)` with 16px blur.
- Accent: violet `hsl(270, 75%, 65%)` and aqua `hsl(190, 80%, 55%)`.
- Status: green success, amber hold, red refuse. Status is never color-only.
- Type: Outfit for titles, Inter for body. Do not switch to Fira.
- Icons: SVG marks, not emoji.

## Motion

Subtle only. Pulse on live status. Honor `prefers-reduced-motion: reduce` with a static badge, not a paused clone of the same animation.

## Product rules

- `/swarm` is the visual overview of the kernel. It cannot admit, activate, spend, or send.
- Unknown health stays unknown. Never infer readiness.
- Dry-run / not-admitted is the default headline, not a footnote.
