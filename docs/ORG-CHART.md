## How to Read This

- **Queens** = domain-level sovereign planners/evaluators.
- **Generals** = VP-style coordinators that own multiple specialist swarms.
- **Swarms** = the actual executing teams (use God Mode router + chosen topology + primitive).
- Every swarm lane declares primary model + fallbacks via the router spec.

This structure can be instantiated per business by copying the generalized templates and mapping names/domains.

See `config/domain-queens.json` for the machine-readable version.
